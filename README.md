# Project Bold Policy Platform

> **First, Best, For All** — UNC Student Government Policy Platform 2026-2027

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

This is a Next.js app ready for Vercel deployment:

```bash
npm run build
```

## Features

- 40 policies across 8 departments
- Real-time progress tracking
- Mobile-first responsive design
- UNC Carolina Blue branding
